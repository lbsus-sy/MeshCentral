# Windows agent installer (GUI EXE)

This folder contains a Windows Forms installer source project. It builds as a **GUI executable** (no console window) and its application manifest requests administrator elevation, so Windows displays a UAC consent prompt before the installer starts.

## Build

On a Windows machine with the .NET 8 SDK:

```powershell
dotnet publish .\customization\client\LakersAgentInstaller.csproj -c Release -r win-x64 --self-contained true -o .\artifacts\installer
```

The resulting `LakersMeshAgentInstaller.exe` is a single-file, self-contained x64 GUI app. GitHub Actions is configured to build this artifact for review; check the workflow result before assuming a successful build. The binary is not Authenticode-signed by this repository; Windows SmartScreen may show an unknown-publisher warning until a trusted code-signing certificate and release-signing process are configured.

## Install an agent

1. In your own MeshCentral server, use its device/agent page to download the Windows agent EXE generated for that server.
2. Run `LakersMeshAgentInstaller.exe`; approve UAC only if you intend to install a persistent remote-management service.
3. Select the generated `MeshAgent*.exe`, check the authorization/trust statement, and confirm installation.
4. Verify the device appears in the intended MeshCentral server. The installer records a local log at `%ProgramData%\LakersMeshCentral\installer.log`.
5. To remove an agent, reopen the GUI installer, choose **Uninstall agent…**, select the installed `MeshAgent*.exe`, and confirm. The wrapper runs the agent's supported `-fulluninstall` command and records the result in the same local log. Verify the service is removed and the device disconnects.

The wrapper runs the MeshCentral Windows agent's `-fullinstall` command to install and `-fulluninstall` to remove it. It does not silently download code, hide the service, disable security software, or suppress the UAC prompt. The user sees the installer UI and a separate confirmation before service installation. A successful process exit is not proof that the agent has connected; verify the device in the server UI.

## Security and consent disclaimer

**Warning — remote-management software:** A MeshCentral agent may enable remote desktop, terminal, file access, and other administrator-authorized functions depending on server permissions. Install only on devices you own or are explicitly authorized to administer, and only when you trust the MeshCentral server that generated the agent. Do not distribute an agent without informing the device owner/administrator. The Windows service is persistent by design and must be visible to the device owner. Never use this tool for covert access, credential collection, evasion, or unauthorized monitoring.

## Build and validation limits

- Source code is provided; the EXE is built by CI, not checked into Git.
- CI builds an unsigned artifact. No private signing key is stored in this repository.
- The installer wrapper expects an agent generated by a compatible MeshCentral server. It does not bundle a universal agent because MeshCentral agents are configured for a specific server.
- The wrapper checks file size and PE signature and shows the selected path, but this is not a substitute for verifying the source and publisher.
