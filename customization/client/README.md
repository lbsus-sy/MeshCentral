# Windows one-file MeshCentral Service installer

The final `LakersMeshAgentInstaller.exe` contains both the wrapper and the Windows agent generated by your own MeshCentral server.

## Build your one-file EXE

1. On your MeshCentral website, create/select the device group and download its Windows Agent EXE.
2. On a Windows PC, install the .NET 8 SDK and Git; clone this repository's `custom/ui-deploy-foundation` branch.
3. Open PowerShell in the repository folder and run:

```powershell
.\customization\client\Build-OneFileInstaller.ps1 -AgentPath "C:\Users\you\Downloads\MeshAgent.exe"
```

The output is `dist\LakersMeshAgentInstaller.exe`. **Only this EXE needs to be copied to the target Windows PC.** The build script embeds the server-specific agent; the target user does not need a second file or .NET.

## Install

Double-click the EXE and approve the normal Windows UAC prompt. It then installs the MeshCentral agent service automatically without a second app popup or console window. Confirm the device appears in your MeshCentral portal. Logs: `%ProgramData%\LakersMeshCentral\installer.log`.

## Uninstall

Run the same matching EXE as administrator with `--uninstall`.

## Security

The embedded payload is server-specific. Rebuild it when the server/device-group agent changes. Treat the EXE as a remote-management installer; share only with authorized users/devices and disclose its behavior to the device owner. UAC is not bypassed. This project does not sign the EXE, so SmartScreen or unknown-publisher warnings may remain. The generic CI artifact does not include an agent; use the script above to create the actual single-file installer.
