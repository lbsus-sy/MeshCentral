# Lakers MeshCentral customization

This repository is a customized fork of [MeshCentral](https://github.com/Ylianst/MeshCentral), the open-source web-based remote device management platform. Upstream license and attribution notices are preserved.

> **Security and consent warning:** MeshCentral is remote-management software. Depending on server permissions, an enrolled agent can enable remote desktop, terminal, file transfer, and other device-management operations. Deploy only on devices you own or are explicitly authorized to administer. Inform device owners/administrators, secure the server with HTTPS and strong authentication, keep backups, and maintain a tested uninstall procedure. Do not use this project for covert access, unauthorized surveillance, credential theft, or security-control evasion.

## Quick start for beginners

### Server: one-command install

Point a DNS A record at an Ubuntu/Debian VPS, allow TCP 80 and 443, SSH in and run:

```bash
curl -fsSL https://raw.githubusercontent.com/lbsus-sy/MeshCentral/custom/ui-deploy-foundation/customization/deploy/install.sh | sudo bash
```

Enter the hostname when prompted. The script installs Docker, builds and starts the customized server behind Caddy for automatic HTTPS. See the [beginner server guide](customization/deploy/README.md).

### Windows: build one EXE that installs the service

In the MeshCentral portal, download the Windows agent for your device group. On a Windows build PC with .NET 8 SDK, run:

```powershell
.\customization\client\Build-OneFileInstaller.ps1 -AgentPath "C:\path\to\MeshAgent.exe"
```

This creates `dist\LakersMeshAgentInstaller.exe`, with the server-generated agent embedded. Copy only that EXE to the authorized target PC, double-click it, and approve the normal UAC prompt. It installs the MeshCentral service without follow-up app popups. See the [one-file installer guide](customization/client/README.md).

The generic EXE produced by CI is only a wrapper and does not contain an agent; the embedded one-file EXE must be built using the agent generated by your own server. The executable is unsigned and may trigger SmartScreen warnings.

## Status and limitations

The one-command installer and one-file build workflow are committed to the customization branch, but they still require a real VPS smoke test and a Windows test install before production use. This branch is not merged into `master`. Remote wallpaper is not integrated as a first-party MeshCentral UI action; the desktop EXE changes the current user's local wallpaper. Diagnostics and crash dump analysis are local and user-initiated. No signed release or end-to-end agent session has been certified.
